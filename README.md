# Stock Market Analysis Using SQL Server

## Project Overview

This project analyzes historical stock market data for six National Stock Exchange (NSE) companies using Microsoft SQL Server. The objective is to examine stock price trends, calculate moving averages, and identify potential trading signals using SQL queries.

## Objectives

* Analyze historical stock market data for six companies.
* Calculate 20-day and 50-day moving averages.
* Identify potential Buy, Sell, and Hold signals based on moving-average comparisons.
* Combine data from multiple stock tables for comparative analysis.
* Retrieve the latest available stock records using Common Table Expressions (CTEs).

## Dataset

The project covers historical stock data from January 2015 to July 2018.

Companies analyzed:

* Bajaj Auto
* Eicher Motors
* Hero MotoCorp
* Infosys
* Tata Consultancy Services (TCS)
* TVS Motors

Each stock dataset contains 889 rows.
